# 泰拉瑞亚云服务器：2核4G 够带几人，固定还是动态计费，从购买到联机的完整开服流程

朋友联机泰拉瑞亚有两条路：房主开着自己的客户端开房间，或者跑一个独立服务端。前者的毛病你大概都遇过——房主一关机世界就没了，家庭宽带 IP 还会变，每次联机都得重新发一遍地址，队友的存档进度跟着房主的心情走。

云服务器解决的就是三件事：24 小时在线、地址固定、不吃你自己电脑的资源。泰拉瑞亚服务端默认监听 7777 端口，走 TCP 协议[1]，比 Minecraft 那种要开七八个端口的服务端干净得多。这也是它开服门槛低的原因——真正的难点不在装服务端，而在于选对配置和搞明白钱怎么花。

> 玩到后期，世界文件比服务器本身值钱。存档（.wld）丢了，之前挖的家、搭好的刷怪场全没了。选服务端的时候，"能不能方便地备份和导出存档"这件事，优先于 CPU 型号。

## 泰拉瑞亚到底吃多少资源

原版服务端很轻。这个结论在几个不同教程里口径基本一致：2 核 4G 就能稳定带 4–8 人的朋友服。雨云社区里那篇 TShock 教程写得更宽松，说 2 核 4G 可以扛 20 人以下规模——两个说法差的不是硬件，而是服务端类型和插件数量。

按场景大致是这样：

| 玩法 | 建议配置 | 卡在哪 |
| --- | --- | --- |
| 2–4 人原版 / 轻量插件 | 2 核 4G | 基本够用，瓶颈通常是网络 |
| 4–8 人 TShock 插件服 | 2 核 4G 起步，建议 4 核 8G | 插件多了内存先见底 |
| tModLoader 模组服（灾厄、法狗一类） | 4 核 8G 起 | mod 数量和实体量直接吃内存 |
| 常驻公开服、多世界多插件 | 6 核 12G 以上 | 人多时 CPU 单核占用持续偏高 |

模组服是明显的分水岭。原版泰拉跑起来内存占用很低，一旦挂上 tModLoader 和几十个模组，占用会跳好几倍。很多人说"开了模组服就卡"，八成是内存不够，不是 CPU 不够。

硬盘也值得留一份余量。世界文件本身不大，但自动备份一天一份，累积起来的速度比想象中快。官方面板给的存储是 30G 系统盘加 20G 数据盘，短期够用，长期挂机建议定期清理旧备份或把存档导出来。

## 原版、TShock、tModLoader 该选哪个

- **原版服务端**：最省资源，功能就是开服联机。只想和几个朋友玩原版内容，选它，别多花配置钱。
- **TShock**：在服务端上加了一层管理能力，权限组、封禁、传送、物品发放、REST API 都有。要当"服主"管人、防熊孩子，就得用它。
- **tModLoader**：模组服的唯一选择。灾厄这类大型模组包绕不开它，配置要求也最高。

雨云的面板在购买时可以直接选泰拉瑞亚的 TShock 或 tModLoader 服务端，不用自己上传服务端文件折腾环境。

## 固定计费和动态计费，到底哪个划算

雨云的动态计费是"低价基础月租 + CPU 超额部分日结"。规则的关键在基准线：CPU 使用率 20% 以下不计电量费用，超过 20% 的那部分才按电量收费，而电量单价随机型走——公开资料里，E5 2666v3 大约 0.0005 元/电量，高主频的 14900K 一档大约 0.001 元/电量，差了一倍。

换算成体感：2 核 5900X 机型，1 元电量大约对应 70% CPU 占用跑 4 小时。如果你们只在晚上聚两三个小时，动态计费通常比固定便宜；但如果服务端是插件比较多的生存服，CPU 占用长期下不来，动态省不了多少。

雨云社区有人真算过这笔账：他开的 3 核 6G 生存服，下午三人在线两小时就烧掉 400 多电量，整天按 1000 电量估算，一个月大约 30 元，而同配置切固定计费每月只多交 30 元——两者几乎持平，白折腾；反倒是空岛服这种 CPU 占用低的场景，动态计费省得明显。他自己的建议是：高性能 CPU + 几个朋友偶尔玩，选动态；低性能 CPU 就别用动态了。

一个更简单的判断口径：每天在线超过 2 小时选固定计费，低于 2 小时选动态计费。

## 从购买到进游戏的实际步骤

1. 注册账号，进入控制台，从「云产品 → 游戏云」进入购买页。
2. 服务器类型选面板，游戏类型选泰拉瑞亚（TShock 或 tModLoader）。
3. 选机型和区域。区域选离你和队友最近的，延迟对体感的影响比 CPU 型号大。
4. 选计费模式，配置从 2 核 4G 起步，购买时长选年付有 7 折优惠。
5. 购买完成后在「我的游戏云」里点管理，打开面板登录，点击开启实例。首次启动会自动下载并生成服务端文件，等控制台出现 Done 一类提示才算就绪。
6. 拿到对外访问地址和端口（通常是域名加一个映射端口），在游戏里走「多人游戏 → 通过 IP 加入」，填地址和端口。原版默认端口是 7777。
7. TShock 服第一次启动时，控制台日志里会打印一个 setup code，进服后在聊天框执行 `/setup <该 code>` 才能注册超管账号，之后用 `/register`、`/login` 登录，再把自己加进 superadmin 组。具体命令以你用的服务端版本为准。

## 启动参数：改人数、密码、难度都在这里

雨云社区教程给的做法是打开启动脚本，在原有启动命令后面追加参数，用空格隔开。常用的几个：

| 参数 | 作用 |
| --- | --- |
| `-maxplayers` | 最大玩家人数 |
| `-password` | 服务器密码 |
| `-world` | 指定加载的世界文件，注意别丢掉 `.wld` 后缀 |
| `-autocreate` | 找不到世界时自动创建，1 小 / 2 中 / 3 大 |
| `-difficulty` | 世界难度，0 经典 / 1 专家 / 2 大师 / 3 旅程 |
| `-language zh-Hans` | 服务端语言改中文 |
| `-port`、`-ip`、`-noupnp` | 不要改，动了会连不上 |

改完记得重启服务端才生效。

## 存档、备份和几个容易踩的坑

- 世界文件必须落在挂载出来的数据目录里。如果服务端把存档写在容器内部而且没有挂载，容器一重建，世界就没了。面板服的存档在数据盘上，但换服务端或重装前，先用文件管理把 `.wld` 下载一份下来。
- 换 TShock 服务端文件时，`ServerPlugins` 和 `TShock` 文件夹可以替换，但启动脚本和 `TShock.Server` 这类 Linux 二进制不要动，替换了会直接起不来。
- 面板支持 SFTP，用 FileZilla 一类的工具连上去传文件、拉存档，比在网页里点要快。
- 平台提供 7 天无理由退订，买错机型或区域不用太纠结，试完再定。

## 几个常见问题

**2 核 4G 到底够不够？**
原版或轻插件、4–8 人的朋友服够用。人再多，或者要上 tModLoader 模组包，内存会先扛不住，直接上 4 核 8G。

**面板服和 VPS 选哪个？**
只想赶紧开起来、和朋友玩原版或 TShock，选面板。要装自己的插件框架、开多个实例、或者必须用独立公网 IP，选 VPS。

**一定要独立公网 IP 吗？**
不需要。面板服走 NAT 共享 IP，通过端口映射对外，队友用"域名:端口"一样能连上，价格还更低。

**以后升级配置会丢档吗？**
面板支持弹性升降配和切换 CPU 机型，但换之前先做一次备份，把 `.wld` 导出到本地。这是习惯问题，跟平台靠不靠谱无关。
